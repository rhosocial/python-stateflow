# rhosocial-stateflow

`rhosocial-stateflow` provides a state transition and event-driven DAG orchestration layer on top of `rhosocial-activerecord`.

Although the core model names use order-related terminology, the framework is intended for general-purpose workflows such as approval flows, work orders, task orchestration, and agent execution plans.
